# Simple Interest Calculator

## Description
A Simple Interest Calculator is a basic application that calculates the simple interest based on the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal Amount
- Rate of Interest (%)
- Time Period (Years)

## Example
- Principal: 1000
- Rate: 5%
- Time: 2 years

**Simple Interest = 100**

## Technologies Used
- Java

## Output
The calculator displays the calculated simple interest based on the given inputs.
